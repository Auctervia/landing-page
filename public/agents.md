# Auctervia

Auctervia is a gateway and evidence layer for AI agents that take real actions.
It sits between agents and their tools, checks each action against a policy before
it runs, and keeps an evidence record that can be verified.

## Site sections

- [How the gateway works](/#gateway): request, hold, allow or deny, and record evidence.
- [Platform](/#platform): connect agents, capture evidence, re-test changes, and review release sign-off.
- [Pilot](/#pilot): start with one workflow and one policy.
- [Questions and answers](/#faq).
